# CLAUDE.md

Instagram content for @ppf.house (PPF installer in Rosario), written with the
`ig-*` skills in `.claude/skills/`.

The voice profile lives at `instagram/voice.md`. The skills read
`~/.claude/instagram/voice.md`, so at the start of a session copy it there:
`mkdir -p ~/.claude/instagram && cp instagram/voice.md ~/.claude/instagram/voice.md`.
